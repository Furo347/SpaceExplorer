# 🚀 SpaceExplorer

**SpaceExplorer** est une application mobile développée avec **React Native (Expo)** permettant d’explorer l’univers à travers les données publiques de la **NASA API**.

---

## 📱 Fonctionnalités

- Affichage de l’**image du jour (APOD)** avec description et crédits.
- Interface simple et responsive.
- Connexion à l’API officielle de la NASA.
- Navigation entre écrans via `@react-navigation/native`.

---

## 🛠️ Technologies

- **React Native / Expo**
- **TypeScript**
- **Axios**
- **React Navigation**
- **NASA Open API**

---

## ⚙️ Installation

### 1️⃣ Cloner le projet
```bash
git clone https://github.com/<ton-nom-utilisateur>/SpaceExplorer.git
cd SpaceExplorer
``` 

### 2️⃣ Installer les dépendances
```bash
npm install
``` 

### 3️⃣ Lancer l’application
```bash
npm start
``` 

Puis scanner le QR code avec Expo Go (Android/iOS)
ou lancer sur un simulateur.

---

## 🔑 Configuration API NASA

### Crée un fichier src/config.ts :
```bash
export const NASA_API_KEY = "DEMO_KEY"; // ou ta clé personnelle
export const NASA_BASE = "https://api.nasa.gov";
```
